## 📌 Purpose

This template provides the minimum evidence required to propose an architectural decision.

## Status

Proposed

## Context

Describe the verified current state, the problem, affected stakeholders, and constraints. Link to source and tests where the current behavior matters.

## Options considered

List viable alternatives, including retaining the current design. Explain material tradeoffs without presenting a predetermined conclusion as analysis.

## Decision

State the selected option in enforceable terms. Identify components, compatibility effects, migration requirements, and ownership.

## Consequences

Record positive effects, costs, operational effects, and conditions that would justify revisiting the decision.

## Security and privacy

Identify changed trust boundaries, sensitive data, failure modes, and required controls. State when the decision has no security or privacy effect.

## Validation

Define tests, documentation, static checks, performance evidence, or operational measures required to prove implementation.
