## Current implementation boundary

Bluewater v8 is a PHP 8.3+ framework for convention-based APIs. It does not provide a cloud control plane, service mesh, message broker, ORM, identity server, or deployment platform. Applications may integrate those systems explicitly through services, middleware, and extensions.
