## Límite actual de la implementación

Bluewater v8 es un framework para PHP 8.3 o posterior destinado a API basadas en convenciones. No proporciona un plano de control en la nube, una malla de servicios, un agente de mensajes, un ORM, un servidor de identidad ni una plataforma de despliegue. Las aplicaciones pueden integrar esos sistemas explícitamente mediante servicios, middleware y extensiones.
